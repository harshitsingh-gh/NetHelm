# NetHELM Landscape Table

| Benchmark | Category | What it tests | What NetHELM imports | Gap NetHELM adds |
|---|---|---|---|---|
| NetConfBench | Config / agentic network tasks | GNS3-based network configuration benchmark | Task format, task taxonomy, baseline harness ideas | Normalized cross-benchmark scoring + safety axis |
| Cornetto | Config repair | LLM-driven network configuration repair | Repair task category / grader ideas | Unified scoring and model fleet |
| NetPress | Network-agent benchmark | Agentic network applications | Safety framing and agent abstraction ideas | Generalized blast-radius metric |
| NIKA | Troubleshooting | Network diagnosis arena | Diagnosis subset | Unified harness |
| TeleQnA / NetEval | Knowledge QA | MCQ networking knowledge | Knowledge category | Not central novelty |
