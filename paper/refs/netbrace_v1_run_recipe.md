Free (no model API; Batfish only). Must be GREEN before spending a cent.

```bash

harness/venvs/nethelm/bin/python scripts/verify_determinism.py \
    --generated 52 --seed 0 --templated-set reroutes --runs 10 --host 127.0.0.1
```

- `--generated 52` MUST cover whatever `--n-generated` the sweep uses (here 52).

## Step 2 — the full paid fleet sweep

The v1 protocol run. `--coarsen-class` is ON by default (audit K1: without it
`modal_by_class` degenerates to the oracle ceiling and the validity floor is
vacuous). Launch **detached** (`setsid`, line-buffered) so a session crash cannot
kill or lose a paid run (memory: feedback_detached_runs).

```bash
# PAID — needs Batfish + every provider key. Step 0 must be GREEN and Step 1 sane first.
setsid harness/venvs/nethelm/bin/python scripts/run_sweep.py \
    --models anthropic/claude-opus-4-8,anthropic/claude-sonnet-4-6,openai/gpt-5.5,openai/gpt-5.4-mini,gemini/gemini-3.5-flash,deepseek/deepseek-v4-pro,kimi/kimi-k2.6,vllm/qwen3-32b \
    --oracle batfish --samples 5 \
    --split both --n-generated 52 --seed 0 \
    --templated-set reroutes --exclude blackhole \
    > runs/v1_sweep.out 2>&1 < /dev/null &
```

- `--samples 5` satisfies the N≥5 stochastic-model rule.
- The headline figure is the templated split's **`reroute_detect`** (NetBrace-Detect /
  Youden's J over the 12 leak-free families), NOT `macro_f1_damage` (gameable on the
  reroute split — an always-fire predictor scores 1.0 because the damage-only macro
  drops the no_op twins). `reroute_detect_all13` is the diagnostic.
- The run writes `runs/sweep_<ts>/`: `summary.{json,md}`, `results.jsonl`,
  `responses.jsonl`, `instances.jsonl`, `completeness.json`. **Check
  `completeness.json` `"complete": true`** before reporting — an incomplete (provider
  503 / circuit-breaker abort) run prints a top-up command per missing cell; pool
  the top-up via `--include` (the `build_clean_gemini.py` contract).
