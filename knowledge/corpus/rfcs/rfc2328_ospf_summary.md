# RFC 2328 — OSPF Version 2 Summary

## Overview
OSPF (Open Shortest Path First) is a link-state IGP for IPv4. Operates directly over IP protocol 89. RFC 2328 (April 1998) is the normative specification. OSPFv3 for IPv6 is defined in RFC 5340.

## Key Concepts

### Areas
- Backbone area: Area 0 (0.0.0.0) — all inter-area traffic must traverse it
- Stub area: no external (Type 5) LSAs; reduces LSDB size
- Totally stubby area: Cisco extension; no Type 3/4/5 LSAs; only default
- NSSA (Not-So-Stubby Area, RFC 3101): allows limited redistribution via Type 7 LSAs
- Area partitioning: if area becomes disconnected, virtual links or redesign required

### Router Types
- Internal router: all interfaces in one area
- ABR (Area Border Router): interfaces in multiple areas; summarizes between areas
- ASBR (AS Boundary Router): redistributes external routes (Type 5 LSAs)
- Backbone router: at least one interface in Area 0

### LSA Types
- Type 1 (Router LSA): each router describes its links; flooded within area
- Type 2 (Network LSA): generated by DR on broadcast/NBMA; describes multi-access segment
- Type 3 (Summary LSA): generated by ABR; describes inter-area prefixes
- Type 4 (ASBR Summary LSA): generated by ABR; location of ASBR
- Type 5 (AS External LSA): generated by ASBR; external routes; flooded everywhere except stubs
- Type 7 (NSSA External LSA): generated by ASBR in NSSA; converted to Type 5 at ABR

### Neighbor States
1. Down — no hellos received
2. Attempt — unicast hello sent (NBMA only)
3. Init — hello received but own router-ID not in neighbor's hello
4. 2-Way — bidirectional; DR/BDR election happens here
5. ExStart — master/slave negotiation for DBD exchange
6. Exchange — DBD packets exchanged
7. Loading — LSR/LSU exchange to fill LSDB gaps
8. Full — LSDB synchronized; adjacency formed

### DR/BDR Election (Broadcast/NBMA Networks)
- Elected per segment; highest priority wins (0 = never DR/BDR)
- Tie-break: highest Router ID
- Non-preemptive: new router with higher priority does NOT preempt existing DR/BDR
- Only DR and BDR form full adjacencies with all routers on segment
- Multicast 224.0.0.6 (all DR routers), 224.0.0.5 (all OSPF routers)

### Hello Protocol
- Hello interval: 10s (broadcast/P2P), 30s (NBMA)
- Dead interval: 4× hello interval default
- Parameters must match: area ID, authentication, hello/dead interval, stub area flag, subnet mask
- Mismatched parameters → neighbors stay in Init/2-Way

### SPF Calculation
Dijkstra algorithm on LSDB. Triggered by:
- LSA received with newer sequence number
- LSA refreshed (30-minute max age refresh)
- Adjacency state change
SPF delay timer (default 5s) prevents rapid re-runs on flaps.

### Metric
OSPF cost = reference_bandwidth / interface_bandwidth. Default reference: 100 Mbps. A GigE link has cost 1 by default (same as FastEthernet) — change reference to 1 Gbps or set costs manually.

## Blast Radius Concepts for OSPF
- Link failure: Type 1 LSA updated; SPF re-run; BGP recursive next-hop may fail if BGP uses OSPF for resolution
- ABR failure: inter-area reachability lost for prefixes only that ABR advertised
- DR failure: BDR promotes to DR; DROTHER must find new BDR; transient loss of LSA flooding
- Area partition: routers in isolated partition lose reachability to backbone
- Max-age LSA: LSA with age=3600 flushes from LSDB; routes withdrawn
- OSPF → BGP interaction: BGP next-hop resolved via OSPF; OSPF route withdrawn → BGP prefix blackholed

## Timers and Convergence
- SPF hold: initial 0–5s, exponential backoff
- LSA generation delay: min 0.1s, max 5s
- Default convergence: ~10–45s (hello/dead interval driven)
- Fast convergence: BFD (RFC 5880) detects link failure in <1s

## Authentication
- Null (type 0): no authentication
- Simple password (type 1): cleartext
- MD5 (type 2, RFC 2154): HMAC-MD5; key ID + sequence number to prevent replay

## OSPFv3 Differences (RFC 5340)
- Runs directly over IPv6
- Link-local scope for hellos; router-to-router adjacencies
- Removed subnet mask from hello; address family agnostic
- New LSA types: Link LSA (type 8), Intra-Area-Prefix LSA (type 9)
- Authentication via IPv6 AH/ESP (not in protocol)
- Instance ID field allows multiple OSPFv3 instances on same link
